# 🐣 팀핏 (TeamFit) - 대학생 팀플 역할 분담 & 모니터링 웹앱

> **"역할 분담 갈등은 줄이고, 업무 현황은 투명하게!"**  
> 대학생 팀 프로젝트를 위한 모던 미니멀 스마트 협업 웹앱

---

## 🌟 프로젝트 소개
대학생들의 팀 프로젝트(팀플) 과정에서 가장 흔히 발생하는 **1위 불편(진행 상황 파악 어려움)**과 **2위 불편(역할 분담 갈등)**을 해결하기 위해 기획·제작된 모바일 맞춤형 협업 웹앱입니다.

귀여운 공식 마스코트 **'핏티(Fitty)'**와 함께 팀원들이 싸우지 않고 즐겁게 과제를 완수할 수 있도록 돕습니다.

---

## ✨ 핵심 기능

1. **공정한 자동 역할 분담 (알고리즘)**:
   - 팀원들의 역할 선호도(자료조사, PPT, 발표 등)를 우선 고려하여 매칭
   - 난이도 가중치 점수(A: 3점, B: 2점, C: 1점) 총합이 팀원 간에 균등해지도록 자동 최적 배분
2. **오늘의 계획 & 진행도 조절**:
   - 팀원별 탭 전환을 통해 오늘 내가 해야 할 일 확인
   - `[미시작]`, `[진행 중]`, `[완료]` 세그먼트 컨트롤러
   - 진행 중 클릭 시 실시간 진행도(%) 슬라이더 및 프리셋(25%, 50%, 75%) 제공
3. **실시간 팀 모니터링 대시보드**:
   - 팀 전체 진행률(%) 및 남은 과제 개수 실시간 요약
   - 팀원별 달성률 (50% 달성 시 축하 뱃지 활성화)
4. **역할 및 일정 재조율 (Rebalancing)**:
   - 미완료 업무 익일 자동 이월
   - 특정 팀원에게 과도한 부하(잔여 점수 3점 이상 편차) 감지 시 불균형 경고 배너 및 담당자 재배정
5. **대학생 편의 기능**:
   - 상단 카카오톡 오픈채팅방 링크 & **참여 코드 원클릭 복사**
   - 구글 드라이브 / 노션 링크 바로가기
   - 테스트용 시뮬레이터 툴바 (`[D+1 다음 날]`, `[샘플 채우기]`, `[초기화]`)

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, Modern Vanilla JavaScript (ES6+), CSS3
- **Styling**: Tailwind CSS, Pretendard Font (Toss/Notion Minimal Theme)
- **Icons**: Lucide Icons
- **Storage**: Browser LocalStorage (별도 서버 설치 없이 100% 브라우저 구동)

---

## 📂 파일 구조
- `index.html` : 메인 웹앱 실행 파일
- `app.js` : 상태 관리, 분담 알고리즘, 마스코트 및 화면 전환 로직
- `style.css` : 토스 스타일 세그먼트 컨트롤러 및 테마 스타일시트
- `계획서.md` : 앱 개발 종합 기능 및 상세 기획서
